# Página Web Personal - Proyecto Final
Este repositorio contiene el código fuente y los recursos de mi página web personal, desarrollada como proyecto para el curso de **Introducción a la Ciencia de la Computación** durante el segundo semestre del año **2024** en la Universidad Católica San Pablo.

## Ver página en vivo
El sitio web fue desplegado originalmente en la plataforma **Neocities**. Puedes visitarlo en el siguiente enlace: https://joaquinalessandronunezmedina.neocities.org/

## Descripción del proyecto
El objetivo de este proyecto es presentar información personal, académica y de contacto en un entorno web. La página incluye secciones sobre:
* **Sobre mí:** Presentación personal, formación escolar e intereses.
* **Cursos:** Materias culminadas y en curso dentro de la carrera de Ciencia de la Computación.
* **Amigos:** Enlaces a las páginas web de compañeros de clase.
* **Contacto:** Redes sociales y correo institucional.

## Contenido del repositorio
Aunque el proyecto está alojado en Neocities, todos los archivos (HTML, CSS e imágenes) han sido subidos a este repositorio para facilitar la visualización, revisión y respaldo del código fuente.
